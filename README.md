# Relevo generacional | Experiencia TED Talk

Experiencia web escenica para la charla de Alma Lopez en Future Leaders Forum,
con 13 momentos operables por teclado y un sistema visual generativo 2.5D.

## Correr local

```powershell
python -m http.server 4173
```

Luego abre:

```text
http://localhost:4173
```

## Controles

- `Espacio` o `Flecha derecha`: avanzar.
- `Flecha izquierda`: volver.
- `F`: pantalla completa.
- `H`: ocultar/mostrar ayuda.
- `R`: reiniciar.
- Selector `ES` / `PT` en la ayuda: cambiar idioma.

Para editar textos, QR y parametros visuales, revisa `GUIA_CAMBIOS_RAPIDOS.md`.
